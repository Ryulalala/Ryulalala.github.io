# GitHub Pages 静的サイト「Ryulalalaの秘密基地」要件定義書

## 1. プロジェクト概要
* **サイトタイトル**: `Ryulalalaの秘密基地` （英語表示時: `Ryulalala's Secret Base`）
* **ホスティング環境**: GitHub Pages
* **プロジェクトの目的**: 学んでいる言語、好きな本、好きな言葉を紹介するとともに、現在学習中・今後学習したい分野をObsidianのグラフビューのようなインタラクティブな水中浮遊アニメーションで可視化・管理するパーソナルサイトの構築。
* **ターゲットデバイス**: PCブラウザ、スマートフォン、タブレット（レスポンシブ対応）

---

## 2. 技術スタック・システム構成
### 2.1 採用技術
* **マークアップ**: HTML5
* **スタイリング**: Tailwind CSS（CDN読み込み方式）＋ カスタムCSS（微調整・アニメーション補助用）
* **プログラミング言語**: Vanilla JavaScript（ES6+）
  * React等のUIフレームワークは使用しない。
  * 保守性・拡張性を高めるため、機能ごとにJavaScriptファイルを分割（ES Modules構成）して実装する。
* **外部JavaScriptライブラリ（CDN読み込み方式）**:
  * **D3.js (`d3-force` 等)** または **物理・グラフ描画系ライブラリ**: 水中を漂うような物理演算、ノード間の線（エッジ）の追従描画、マウス／タッチドラッグ操作の制御に使用。
  * **GSAP（必要に応じて）**: 四角が分裂する際のトランジション演出の補助に使用。
* **データ管理**: JSON形式（外部JSONファイルを `fetch` APIで非同期読み込み）

### 2.2 ディレクトリ・ファイル構成（拡張性重視の分割構成）
GitHubリポジトリへそのままプッシュして動作するビルドレス構成とし、今後のコンテンツ追加や機能拡張を行いやすいよう以下のファイル分割とする。

```text
root/
├── index.html          # メインHTML（セクション1〜4の骨格とCDN読み込み）
├── css/
│   └── style.css       # Tailwindの補助スタイル、水中表現やカスタムアニメーション定義
├── js/
│   ├── main.js         # エントリーポイント（全体の初期化・イベント統合）
│   ├── i18n.js         # 日本語 / 英語（JA / EN）の多言語切り替え制御モジュール
│   └── graph.js        # セクション4の水中浮遊・分裂アニメーション・グラフ描画モジュール
└── data/
    ├── site-text.json  # セクション1〜3およびUIラベルの日英テキストデータ
    └── graph-data.json # セクション4の大ジャンル・細かなジャンル・関連線・URLデータ
```
※ローカル開発時は、`fetch()` によるJSON読み込みのCORS制約を回避するため、簡易ローカルサーバー（VS Code Live Server や `python3 -m http.server` 等）上で動作確認を行う。

## 3. 画面構成・デザイン要件
### 3.1 レイアウト構成
* **シングルページ・縦スクロール構成**:
  * 画面上部から順に、ヘッダー（タイトル＋言語切替）、セクション1、セクション2、セクション3、セクション4を縦方向に配置する。
  * セクション1〜3はシンプルな最小構成とし、画面下部の**セクション4に大きめの専用枠（ビューポートの70〜85%程度の高さを確保したコンテナ）**を設け、その枠内でグラフアニメーションを展開する。

### 3.2 デザインテーマ・配色
* **ベーステーマ**: ダークモード基調（深海や静かな秘密基地を想起させる落ち着いたダークトーン）
  * ページ背景色案: `#0f172a`（Slate 900）〜 `#090d16`
  * グラフ枠内背景色案: `#020617`（Slate 950、わずかなグラデーション等で水中の奥行きを表現）
  * 基本テキスト色案: `#f8fafc`（Slate 50）〜 `#cbd5e1`（Slate 300）
* **グラフノード（四角）の枠線カラー（リンク有無の視覚的区別）**:
  * **外部リンクあり（遷移するノード）**: シアン／アクアブルー系（例: `#38bdf8` / Tailwind `border-sky-400`）＋ 微弱な発光（グロー）エフェクトを付与し、クリック（タップ）可能であることを直感的に示す。
  * **外部リンクなし（遷移しないノード）**: スレートグレー系（例: `#64748b` / Tailwind `border-slate-500`）の落ち着いた枠線とする。
  * **大まかなジャンル（初期表示ノード）**: インディゴ／ティール系（例: `#818cf8` / Tailwind `border-indigo-400`）のやや太めの枠線。

### 3.3 多言語対応（日本語 / 英語切り替え）
* ヘッダー右上に言語切り替えボタン（`JP / EN`）を配置する。
* 切り替え操作により、ページを再読み込みすることなく以下すべてのテキストが日本語／英語に切り替わる。
  * サイトタイトル、各セクションの見出し
  * セクション1〜3の項目テキスト
  * セクション4のグラフ内のジャンル名（大ジャンル・細かなジャンル）

### 3.4 デバイス別操作マッピング（PC / スマホ・タブレット）
タッチデバイスでの操作性を損なわないよう、ポインター種別（または画面幅・タッチイベント有無）に応じて以下の通り操作を割り当てる。

| 操作目的 | PCブラウザ（マウス操作） | スマホ・タブレット（タッチ操作） |
| :--- | :--- | :--- |
| **大ジャンルの展開（分裂）** | 四角を**ダブルクリック** | 四角を**シングルタップ** |
| **細かなジャンルのリンク遷移** | 四角を**ダブルクリック** | 四角を**シングルタップ** |
| **初期表示（大ジャンル一覧）へ戻る** | グラフ背景エリアを**ダブルクリック** | グラフ背景エリアを**シングルタップ** |
| **四角（ノード）の位置移動** | **マウスドラッグ** | **タッチドラッグ（スワイプ移動）** |

## 4. セクション別機能・コンテンツ仕様

### 4.1 セクション1：学んでいる言語
* **初期表示仕様**: テキストのみの最小構成（後からアイコンや習熟度などを拡張しやすいHTML構造とする）。
* **表示項目**:
  * Python
  * Scala
  * Javascript
  * 英語（English）

### 4.2 セクション2：好きな本
* **初期表示仕様**: テキストのみの最小構成（後から書影や感想リンクを追加しやすい構造とする）。
* **表示項目**:
  * The meaning of your life

### 4.3 セクション3：好きな言葉
* **初期表示仕様**: テキストのみの最小構成（引用ブロック `<blockquote>` を用いたタイポグラフィ表示）。
* **表示項目**:
  > God, give us grace to accept with serenity
  > the things that cannot be changed,
  > Courage to change the things
  > which should be changed,
  > and the Wisdom to distinguish
  > the one from the other.

---

### 4.4 セクション4：これから学習したいこと・学習しているもの（インタラクティブ・グラフビュー）

#### (1) 状態1：初期表示（大まかなジャンル一覧モード）
* **表示要素**:
  * 「大まかなジャンル」を少し大きめの四角（矩形ノード）で表示する。
  * 初期ジャンル：「数学」「プログラミング」「文学、哲学」の3つ。
* **アニメーション・操作挙動**:
  * 四角は水の中を泳ぐ（漂う）ような感覚で、常時ゆっくりと滑らかに浮遊移動し続ける（枠外へはみ出さないよう境界反発・引力制御を行う）。
  * マウスドラッグ（タッチドラッグ）で四角を任意の場所へ引っ張って動かすことができる。
* **詳細表示への遷移**:
  * 任意の大まかなジャンルの四角をダブルクリック（タッチ端末はシングルタップ）すると、状態2（詳細表示モード）へ遷移する。

#### (2) 画面遷移アニメーション（分裂エフェクト）
* ダブルクリック（タップ）された大まかなジャンルの四角を中心に、内部から細かなジャンルの四角が分裂して広がるようなアニメーションを実行する。
* 同時に、選ばれなかった他の「大まかなジャンル」の四角はフェードアウトして非表示になる。

#### (3) 状態2：詳細表示（細かなジャンルのグラフビューモード）
* **ヘッダー表示**:
  * グラフ枠内の**左上**に、現在選択されている「大まかなジャンル名」を大きく表示する。
* **表示要素（ノードと線）**:
  * 選択された大ジャンルに属する「細かなジャンル」の四角（ノード）を表示する。
  * 関連性のある細かなジャンル同士を、**方向性のない単なる線（無向エッジ）**で結んで表示する（Obsidianのグラフビュー風）。
* **アニメーション・操作挙動**:
  * 分裂後の細かなジャンルの四角も、水中を漂うように常時ゆっくりと動き続ける。
  * ユーザーはマウスドラッグ（タッチドラッグ）で細かなジャンルの四角の位置を自由に動かすことができ、移動に合わせて繋がっている線もリアルタイムに伸縮・追従する。
* **外部サイトへの遷移（リンク機能）**:
  * 細かなジャンルは「サイトに飛ぶもの（リンクあり）」と「飛ばないもの（リンクなし）」に分かれる。
  * **枠線の色**によって両者を視覚的に区別する（3.2節参照）。
  * 「サイトに飛ぶもの」をダブルクリック（タッチ端末はシングルタップ）した場合、設定されたURL（GitHubページやYouTube等、初期はダミーURL）を**別タブ（`target="_blank"` `rel="noopener noreferrer"`）**で開く。
  * 「飛ばないもの」はダブルクリック（タップ）しても画面遷移しない。
* **初期表示への復帰操作**:
  * グラフ枠内の**背景エリア（四角が重なっていない空白部分）**をダブルクリック（タッチ端末はシングルタップ）すると、細かなジャンルが収束（またはフェードアウト）し、状態1（大まかなジャンル一覧モード）へ戻る。

## 6. 非機能要件・運用要件
1. **拡張性・メンテナンス性**:
   * 新しいジャンルや学習項目、関連線を追加する際、JavaScriptコードを修正することなく `data/graph-data.json` の編集のみで完結する設計とする。
   * セクション1〜3の拡張時も、HTMLおよびテキスト用JSONの追記のみで対応できる疎結合な構造を保つ。
2. **パフォーマンス**:
   * 水中浮遊アニメーションは `requestAnimationFrame`（またはD3のタイマー制御）を用い、画面外にスクロールしている間は負荷を抑えるなどブラウザのフレームレート低下を防ぐ配慮を行う。
3. **ブラウザ互換性**:
   * モダンブラウザ（Google Chrome, Safari, Firefox, Microsoft Edge の最新バージョン）および iOS Safari / Android Chrome で正常に動作すること。
